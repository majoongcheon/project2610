樂 국악기 이야기우리 소리를 내는 악기들

줄을 뜯고, 불고, 두드리는
우리 악기를 만나 보세요

이 페이지의 배경음악은 Klassic API 로 만듭니다. [배경음악 선택]에서 곡과 악기를 고르면, Klassic 의 악보 공유하기에 올라온 악보를 고른 국악기 소리로 연주해 들려 드립니다.

    이 페이지는 이렇게 만들었습니다

    1. Klassic 에 가입하고 API 접근 키를 받았습니다(키는 이 사이트 서버에만 둡니다).
    2. 사이트 서버가 GET /v1/shared-scores 로 곡 목록, GET /v1/instruments 로 악기 목록을 가져옵니다.
    3. 곡을 고르면 GET /v1/shared-scores/{번호}/score 로 악보(MusicXML)를 받고, POST /v1/render/mp3 에 악보와 악기를 보내 MP3 를 만듭니다.
    4. 만든 MP3 는 한 시간 동안 사이트 서버에 두고 다시 씁니다(호출 한도 절약).
