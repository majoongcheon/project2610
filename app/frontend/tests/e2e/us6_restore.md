# US6 편집 자동 저장·복원 — 수동 E2E 점검표 (T122)

> 헤드리스 Chrome 이 팀 서버에서 돌지 않으므로(research R21) **개발자 PC에서 Playwright(또는 손으로)** 돌린다.
> 근거: FR-028 · UC6 A2 · SD_02 §5-2 "자동 저장 복원 질문" · `frontend/src/stores/editor.ts`(IndexedDB `gugak-editor` / `autosave`, 키 = 요청 번호)

## 준비
1. 웹 서비스(9523)·모델 API(9543)를 띄우고 `http://127.0.0.1:9523/` 을 연다(개발 서버면 `/soundfonts` proxy 확인 — `assets/soundfonts/SOURCES.md` §3).
2. `shared/fixtures/` 의 MIDI 한 개를 올려 결과를 받고 [편집하기]로 S2(`/r/<요청 번호>/listen`)에 들어간다.
3. DevTools → Application → IndexedDB → `gugak-editor` 가 보이는지 확인.

## 한 번 돌리기 (이것을 10회 반복)

| # | 할 일 | 기대 |
|---|---|---|
| 1 | 트랙 1 악기를 **대금**으로 바꾼다 | 상태 줄 "편집본 · 기기에 자동 저장됨 (시:분)" |
| 2 | 조옮김 [+] 두 번 | 값 `+2`, 악보가 다시 그려진다 |
| 3 | 음표 고치기에서 첫 음 ▲ 한 번, 음량 '크게' | 목록 값이 바뀐다 |
| 4 | [트랙 추가] (해금) | 트랙 표에 "추가 (선율 복사)" 줄 |
| 5 | **브라우저를 강제로 닫는다**(탭 닫기가 아니라 프로세스 종료: macOS `kill -9 <Chrome PID>` 또는 Playwright `browser.close()` 없이 `context` 버리기) | — |
| 6 | 브라우저를 다시 열어 같은 주소(`/r/<번호>/listen`)로 간다 | "지난번 편집이 남아 있어요. 이어서 할까요?" 상자가 **한 번** 뜬다. 편집 건수 = 1~4단계 연산 수 |
| 7 | [이어서] | 악기 대금 · 조옮김 +2 · 첫 음 변경 · 해금 트랙이 모두 복원. [재생]하면 편집본 소리 |
| 8 | 새로 고침(F5) | 같은 탭에서는 다시 묻는다(저장본이 남아 있으므로). [처음부터]를 누르면 원본으로, IndexedDB 줄이 지워진다 |
| 9 | [원본으로 되돌리기] → [되돌리기] | 편집이 모두 사라지고 IndexedDB 줄도 지워진다. 상태 줄 "원본과 같아요" |
