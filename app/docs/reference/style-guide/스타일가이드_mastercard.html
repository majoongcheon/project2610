상태 색 선택: 원본에는 오류·성공 색이 없다. 그래서 새 색을 만들지 않고 기존 토큰에서 골랐다 — 완료·진행 = 먹, 대체 결과 = Link Blue(원본의 안내 색), 반려 = Clay Brown, 주의 = Light Signal Orange 점, 대기·만료 = Slate Gray. Signal Orange는 원본 규칙대로 동의에만 남겨 두었다. Mastercard 로고 빨강(#EB001B)·노랑(#F79E1B)은 UI 색이 아니므로 쓰지 않는다. 서비스 확장 색: 없음.

글꼴

한 가족 글꼴. MarkForMC 대신 원본 fallback인 Sofia Sans, 한글은 Noto Sans KR(가변 글꼴이라 450 굵기가 그대로 나온다). 제목은 500 + 자간 -2%, 본문은 450. 대문자는 14px 눈썹 라벨에만 쓰고, 명조는 쓰지 않는다(원본: 서체 섞지 않기).

04 · Rules

규칙

원본 Do's and Don'ts에 서비스 규칙을 더했다.

할 것

  • 바탕은 한지빛 Canvas Cream(#F3F0EE). 표면 순서는 한지 → Lifted Cream → 먹 하단
  • 주요 버튼은 먹빛 알약(모서리 20), 글자는 순백이 아닌 크림
  • 제목은 500 + 자간 -2%, 본문은 450
  • 기능 그림은 원형(장구 면·정간 원형 크롭)으로 자르고, 오른쪽 아래에 흰 위성 버튼
  • 눈썹 라벨 앞에는 작은 주황 점
  • 상태는 칩(기호 + 글자)과 안내 상자 테두리로 — 색만으로 뜻을 전하지 않는다
  • 반려(채운 적갈 칩, role="alert")와 대체 결과(파란 테두리 칩)를 모양부터 다르게
  • 메뉴는 흰 알약으로 화면 위에서 24px 띄운다

하지 말 것

  • Signal Orange를 동의 밖에서 쓰기 — 마케팅 버튼·반려 표시 금지
  • 대체 결과에 반려 색을 쓰기 — 대체는 실패가 아니다
  • 순백 페이지 바탕, 8–16px 모서리
  • 서체 섞기 — 명조·손글씨·장식 글꼴 금지
  • 14px 눈썹 라벨 밖의 대문자
  • 딱딱한 그림자 — 48px 이상 퍼짐, 10% 이하만
  • hover 변형 만들기 — 눌림(active)만 정의
  • Dust Taupe·Light Signal Orange를 글자색으로 쓰기(대비 1.40·2.53)
  • Mastercard 빨강·노랑·로고 쓰기 — 마크는 정간 격자
  • 메뉴 링크를 6개보다 많이 두기
